#### 8.3 ~ 8.10 八种金属的装备章（每章 3 页 + "后页"锻造）

> ★ **每章的排版规则**：
> - **第 1 页左** = 武器工具（含"任何手段的攻击都能触发"那句）
> - **第 1 页右** = 盾牌
> - **第 2 页左** = 盔甲
> - **"后页"** = 该金属装备的**锻造方式**，**按固定顺序挂 14 件**：
>   **剑 / 重锤 / 三叉戟 / 弓 / 弩 / 斧 / 镐 / 锹 / 锄 / 盾牌 / 头盔 / 胸甲 / 护腿 / 靴子**
