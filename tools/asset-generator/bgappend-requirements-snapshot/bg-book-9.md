#### 9.2 章节 1 · 关于易金商人（封面：**易金柜台**）

| 页 | 内容（**逐字用**） |
|---|---|
| 1 左 | 易金商人是我们炼金术师们的最大供应商兼中间商，他的出现可以为我们提供更加便利且大众化的直购方式从而获取那些珍贵的材料。 |
| 1 右 | **（上边挂：易金柜台配方）** 你便可制作这种易金柜台，将村民转化为易金商人吧。 |
| 2 左 | **（中上边挂：礼品金票）** 不过有一点需要注意的就是易金商人的支出与支入的主要货币并不是绿宝石，而是礼品金票，而礼品金票的主要获取来源便是在万坚金武器工具上面，所以他可能便是我们拥有"贵金"器具这么一个凭证之后，才能与之交易的存在。 |

#### 9.3 章节 2 · 礼品盒

| 页 | 内容（**逐字用**） |
|---|---|
| 1 左 | 这些便是跟易金商人交易从而获取的礼盒，每一种盒子里都藏匿着不同样的珍宝。 |
| 1 右 | **（中上边放：万宝礼物盒）** 万宝礼物盒内可以开出**任意 6 种**原版的各种遗迹所开出来的物品，其中就包括了掠夺者前哨站，林地府邸，丛林神庙，沉船，埋藏的宝藏，沙漠神殿，远古城市，试炼密室，遗迹堡垒，下界要塞，要塞，末地城（不过**不会在该礼品盒内开出锻造模板**，且**不联通第三方模组所塞入以下遗迹战利品表的物品**）。 |
| 2 左 | **（中上边放：珍品古董盒）** 珍品古董盒内可以开出没人要的老古董，也有一定几率在内开出一种古董武器工具（其实这种礼品盒**也可以在远古城市的箱子内开到**）。 |
| 2 右 | **（中上边放：没人要的老古董）** 没人要的老古董可以作为能够造成 **3 点伤害**的投掷品使用，还可以用于在**铁砧**上为古董武器工具进行修复，但它其实还有**一个用途**，那就请你移步至「**〔待补〕**」这个章节里面谢谢（其实这个古董**也可以在远古城市的箱子内开到**）。<br>⚠ **引号里是空的** ⇒ 见 §9.5 |
| 3 左 | **（中上边放：金雕礼品盒）** 金雕礼品盒顾名思义就是专门开出各种金雕摆件的礼品盒，为你的房间添加一个这样的金雕可倍儿有面啊！ |
| 3 右 | **（中上边放：金享珍味盒）** 金享珍味盒内可以开出 **3 种金食物**（其中包括着原版的金苹果与金胡萝卜甚至是农夫乐事联动的），同时也有一定几率在内开出**万坚金食物**。 |
| 4 左 | **（中上边放：炼金珍材盒）** 炼金珍材盒内可以开出**任意一种炼制"贵金"所需的核心材料**，不过在跟易金商人萍水相逢的情况下他可不会就这么轻易的直接卖给你，得给他的**村民等级拉到专家级别**才能为你售卖哦。 |

#### 9.4 章节 3 · 古董器具（封面：**万古烬骸剑**）

| 页 | 内容（**逐字用**） |
|---|---|
| 1 左 | **（中上边摆：古董 剑/斧/镐/锹/锄/刀，**按此顺序不断替换**；上边字体「古董武器工具」）** 古董武器工具可以在珍品古董盒内有概率开出（**如果安装了农夫乐事则会有概率开出古董屠刀**）其攻击伤害和挖掘能力**将近钻石**武器工具，但**耐久却比铁工具要低一些**，且**挖掘等级也与铁相近**，但你也别因此小看了它们，那么就只需要做出**下界合金古董升级模板**，并配合着**下界合金锭**将古董武器工具升级成**下界合金**的变体。 |
| 1 右 | **上：下界合金古董升级的配方**（**两种配方随时间不断变换**）<br>**下：下界合金古董武器工具的配方**（**六种器具的配方随时间不断变换**） |
| 2 左 | **（中上边放：万古烬骸剑 与 幽冥断骸刀，随时间不断替换；上边字体「下界合金古董武器」）** 万古烬骸剑与幽冥断骸刀在攻击目标时有**极小的概率**在目标身旁掉落**下界合金尘埃**，并且会受**抢夺**附魔的影响提升这种尘埃的**掉落率和掉落量**。 |
| 2 右 | **（中上边放：下界合金古董 斧/镐/锹/锄，随时间不断替换；上边字体「下界合金古董工具」）** 九幽裂骸斧，黄泉引骸镐，修罗噬骸锹，苍冥祭骸锄在挖掘方块时会有**一定几率**将挖掘下来的方块**转换为**下界合金尘埃，并且会受**时运**附魔的影响提升这种尘埃的**掉落率和掉落量**，其中**黄泉引骸镐**还能把挖掘下来的**远古残骸**直接转换为 **1~3 个**的下界合金碎片，也同样会受时运影响提升碎片的掉落率和掉落量。 |
| 3 左 | 当你凑齐**九个下界合金尘埃**时便能做出一个**小下界合金碎片**出来，再凑齐**九个小下界合金碎片**便能做出一块**完整的下界合金碎片**了 |
| 3 右 | 放出**下界合金尘埃 → 小下界合金碎片**，再到**小下界合金碎片 → 下界合金碎片**的配方 |
| 4 左 | 备注：**下界合金古董工具是不会把下界合金块和各种"贵金"建筑方块直接就地转换为下界合金尘埃的**，不过**尘埃该掉落还是会掉落的**请你们放心，不然你们还想要看到下克上啊那得有多亏呀！ |
