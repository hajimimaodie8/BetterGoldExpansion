### 6.1 章节 1 ·「贵金」的副要材料（章节封面：**混合晶石堆**）

| 页 | 左侧文案（**逐字**） | 右侧挂什么 |
|---|---|---|
| **1** | 以金块为主基，再搭配上钻石的尊贵，红石的高能，石英的锐利，紫水晶的神秘，还有下界合金稳定，再加上某种心材料作为媒介"贵金"便可在此炼成，不过我们的小合成表肯定是放不下那么多材料的，所以说嘛…先把这三样晶石合起来吧。 | **混合晶石堆的配方** |

### 6.2 章节 2 ·「贵金」的核心材料（章节封面：**金钱贝**）

| 页 | 左上角图标 | 左侧文案（**逐字**） | 右侧挂什么 |
|---|---|---|---|
| **1** | （无） | 要想炼制"贵金"还得需要一样核心材料作为媒介，不同样的核心材料所炼制出来的"贵金"色泽，能力便会彼此不同。 | **中上角：炼金珍材盒**；<br>**右侧正文**：核心材料的获取包括着打某种怪，挖掘某种东西，甚至是可以自己直接制作，不过比较更加大众化的便是从易金商人交易而炼金珍材盒，不过这种礼品盒他可不会卖给初学者，看样子得跟他讨好一些关系啊。 |
| **2** | **高燃烈焰棒** | 高燃烈焰棒作为以火元素为载体的核心材料获取方式确实还算简单了，只需要在下界要塞多弄一点烈焰棒再掺一点火药就能够直接制作，使用此原料炼制而成的"贵金"便被称之为「烈燃金」。 | **上：高燃烈焰棒的配方**<br>**下：烈燃金原料的配方** |
| **3** | **金钱贝** | 金钱贝作为以金元素为载体的核心自然深受猪灵们的喜爱，尤其是猪灵蛮兵就经常拿着这玩意在遗迹堡垒内到处显摆，因此我们便可向全体猪灵一族展开杀戒便可获得，就算你打不过也没关系，你也可以与猪灵们采用以物易物用这种和平的方法来获取，使用此原料炼制而成的"贵金"便被称之为「万坚金」。 | **万坚金原料的配方** |
| **4** | **闪耀藤条** | 闪耀藤条作为以木元素为载体的核心材料获取可能需要较高的运气，只需要使用任意金工具挖掘树叶与藤蔓有较小的几率才能掉落，这就意味着这可是你在拥有"贵金"工具以后才能拥有的物品，使用此原料炼制而成的"贵金"便被称之为「树棘金」。 | **树棘金原料的配方** |
| **5** | **集束回响碎片** | 集束回响碎片作为以幽元素为载体的核心材料获取可能较为艰难，只需要在远古城市内多收集一些回响碎片再使用幽匿脉络作为捆绑碎片的绳子就能够直接制作，使用此原料炼制而成的"贵金"便被称之为「幽咆金」。 | **上：集束回响碎片的配方**<br>**下：幽咆金原料的配方** |
| **6** | **靛蓝海洋之心** | 靛蓝海洋之心作为以水元素为载体的核心材料虽然流程比较简短但还需要不少的机遇才能得到，只需要给海洋之心裹上了一些青金石块就能够直接制作，使用此原料炼制而成的"贵金"便被称之为「靛海金」。 | **上：靛蓝海洋之心的配方**<br>**下：靛海金原料的配方** |
| **7** | **巫毒羽毛** | 巫毒羽毛作为以毒元素为载体的核心材料受众不用多想肯定是女巫啦，但你击杀女巫并将这根羽毛取走后你便会发现这个羽毛其实是个…二手量产品？！并且你第一次获得这根羽毛后还可以使用哭泣的黑曜石，发酵蜘蛛眼跟羽毛进行复制出一个，使用此原料炼制而成的"贵金"便被称之为「巫毒金」。 | **上：巫毒羽毛的「复制」配方**<br>**下：巫毒金原料的配方** |
| **8** | **聚紫能晶尘** | 聚紫能晶尘作为以雷元素为载体的核心材料获取方式也应该还算简单一点吧，只需要使用精准采集将紫水晶簇完全取下，再搭配上红石粉最后将这俩用砂轮碾一下就能够直接制作，使用此原料炼制而成的"贵金"便被称之为「结雷金」。 | **上：聚紫能晶尘的配方**<br>**下：结雷金原料的配方** |
| **9** | **紫颂樱花枝** | 紫颂樱花枝作为以幻元素为载体的核心材料便是在末地巨龙泯灭之后兴起的，只需要加一些樱花树苗配上紫颂花和恶魂之泪就能够直接制作，使用此原料炼制而成的"贵金"便被称之为「幻惑金」。 | **上：紫颂樱花枝的配方**<br>**下：幻惑金原料的配方** |

### 6.3 章节 3 ·「贵金」的知识

| 页 | 左（含左上角图标 + 逐字文案） | 右（含左上角图标 + 逐字文案） |
|---|---|---|
| **1** | 图标：**各种各样的"贵金"锭**（随排版顺序变化）<br>把"贵金"原料丢进熔炉或高炉烧成锭，即可制成**建材**（建筑方块：锭块 / 砖块 / 柱 / 楼梯 / 台阶 / 砖墙 / 栏杆 / 门 / 活板门 / 链 / 灯笼），或与其对应核心材料做成的**锻造模版**升级**金装备**。 | 图标：**"贵金"装备的升级锻造模版**（随排版顺序变化） |
| **2** | 图标：**烈燃金建筑方块**<br>使用烈燃金制成的建筑方块在踩踏，贴近，破坏，右键交互会给予目标6秒的火焰伤害。 | 图标：**万坚金建筑方块**<br>万坚金制成的建筑方块是为数不多没什么特别效果的，如果你不追求某种防卫只追求外观，那么万坚金建筑方块肯定是你的不二之选。 |
| **3** | 图标：**树棘金建筑方块**<br>使用树棘金制成的建筑方块在踩踏，贴近，破坏，右键交互会对目标造成1点仙人掌伤害，但它们并不会像真的仙人掌一样损坏掉落物。 | 图标：**幽咆金建筑方块**<br>使用幽咆金制成的建筑方块在踩踏，贴近，破坏，右键交互会对3×3×3目标造成3点监守者声波伤害并击退目标。 |
| **4** | 图标：**靛海金建筑方块**<br>靛海金制成的建筑方块也是为数不多对绝大部分生物没什么特别效果的，只不过会对踩踏与贴近该金属建材时的末影人，烈焰人，雪傀儡，炽足兽这种恐水性生物造成伤害。 | 图标：**巫毒金建筑方块**<br>使用巫毒金制成的建筑方块在踩踏，贴近，破坏，右键交互会给予目标1级6秒的中毒状态。 |
| **5** | 图标：**结雷金建筑方块**<br>使用结雷金制成的建筑方块在踩踏，贴近，破坏，右键交互会给予目标1级6秒的虚弱状态。 | 图标：**幻惑金建筑方块**<br>使用幻惑金制成的建筑方块在踩踏，贴近，破坏，右键交互会给予玩家和友善生物和一部分中立生物1级6秒的生命恢复状态。 |
