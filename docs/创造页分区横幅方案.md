# 创造模式「分区横幅」实现方案（航空学同款）

素材：`assets/bettergold/textures/gui/creative_sections/{materials,blocks,gear,food,fd}.png`，5 张 **162×18**，
与 Aeronautics 的横幅完全同规格。

> **1.4 定稿（现状）**：本模组**只有一个创造页**（`bettergold:bettergold_tab`，排在所有原版页之后），
> 5 张横幅就是这一页里的 **5 个分区**：材料 / 建筑 / 食物 / 装备 / 乐事。
> 每个分区是**一个连续的物品列表**，分区内部的先后（其他材料 → 交易金商人相关 → 金属 ……）
> **只是列表里的次序，不再各占一条横幅、也不插额外空行**。
> 实测：`SECTION_ROWS` 恒为 5 条记录；物品 206 = 本体 175 + FD 乐事 31（未装农夫乐事时 4 个分区 / 175 件）。

## 一、机制（读 Aeronautics 源码确认，非猜测）

参考实现：`Creators-of-Aeronautics/Simulated-Project`，包 `dev.simulated_team.simulated.mixin.creative_tab_sections`。
- `CreativeModeTabMixin`：`@WrapMethod("buildContents")` **整个接管标签页的物品构建**，自己往 `displayItems` 塞物品
  → 因此可以自由决定顺序、并在分区之间插入空行
- `SimulatedCreativeTab.processItems/padMenuItems`：按分区顺序输出物品；每个分区之后补空格子（补满当前行 **再空一整行**），
  横幅就画在那条空行上；同时记录每个分区的行号（`SECTION_Y_VALUES`）与物品数（`SECTION_ITEM_COUNTS`）
- `CreativeModeInventoryScreenMixin`：注入 `render` 的 TAIL，**只在自己标签页被选中时**调 `renderBanners()`；
  用 Accessor 取 `leftPos/topPos`（+8/+17 对齐物品格）；`分区行号 − 当前卷动行` 落在 0~4 才画（横幅随滚动）
- 绘制：`graphics.blitSprite(横幅, x, y, 162, 18)` → 左侧画释词底方块 → 写释词
- 提示框：注入 `getTooltipFromContainerItem` 把分区名插进物品 tooltip（可选）
- 多加载器：`SimTabService` 接口 + `META-INF/services` 分发（我们是纯 NeoForge，用不上）

**我们的做法（不引入 Mixin）**
- 排布：直接写在现有标签页的 `displayItems` 里（我们本来就是代码构建的）
- 画横幅：客户端 `ScreenEvent.Render.Post`；`leftPos/topPos` 用原版创造界面的居中布局（195×136）或反射读取
- 卷动行号：反射读创造界面的滚动状态字段，按原版公式换算首个可见行

## 二、分区表（1.4 定稿：一页 5 个分区，每区一条横幅）

| 分区（横幅贴图 / 释词） | 分区内物品顺序（**一个连续列表**，中间不插横幅、不插空行） |
|---|---|
| 材料 `materials.png` | 其他材料 → 交易金商人相关（礼品金票 + 四种礼盒）→ 金属（按金属顺序，每个金属：核心材料 → 原料 → 锭 → 粒 → 模板） |
| 建筑 `blocks.png` | 金属块 → 金属建材（每金属：砖块 → 柱 → 楼梯 → 台阶 → 墙 → 门 → 活板门 → 栏杆 → 链 → 灯笼）→ 其他建筑方块（普通金套件同一类型序，同类型多种材料按物品 id；套件之后是杂项，定稿顺序：**金染土 → 金麦块 → 筐装方块（一整组，组内按物品 id）→ 易金柜台 → 金雕（苦力怕 → 末影人 → 青蛙）**，未命中该表的其它杂项排最后） |
| 食物 `food.png` | 种子 → 普通金食物 → 万坚金食物 |
| 装备 `gear.png` | 金属装备（每金属：剑 → 斧 → 镐 → 锹 → 锄 → 头盔 → 胸甲 → 护腿 → 靴子）→ 其他工具（金钥匙 → 古董工具 → 下界合金古董工具） |
| 乐事 `fd.png` | 小刀（**烈燃金刀 → 万坚金刀 → 巫毒金刀 → 结雷金刀 → 古董刀 → 下界合金古董刀**，金属刀按金属出场顺序、非金属刀排其后）→ 普通金食物 → 金放置食物 → 万坚金食物 → 万坚金放置食物（由 FD 模块自己注入） |

实现落点：分区（key / 释词 / 横幅 / 候选物品 / 内部顺序）在 `material/CreativePageSections`；
分区内部的顺序规则在 `material/CreativeTabSections`（`ordered()` 首尾相接成一条列表）；
排布与行号在 `material/CreativeSections#layout` + `SECTION_ROWS`（键 = 分区 key）；
渲染在 `client/CreativeSectionBanners`（按分区 key 取该分区的横幅与释词）。

## 三、必须"规则驱动"（以后金属会非常多，联动方已备好 16 色）

**绝对不要**为每种金属写一条横幅或一段分支。做法：

1. **金属顺序只在一处维护**：`MetalFamily` 里加一个有序列表（万坚金、烈燃金、巫毒金、结雷金、……以后 append），
   新金属注册后自动获得位置；分区横幅固定只有"金属 / 金属块 / 金属建材 / 金属装备"这几条。
2. **靠 id 后缀判定归类与排序**，不枚举物品：

   | 后缀 | 分区 | 区内序 |
   |---|---|---|
   | `blazing_rod` / `voodoo_feather` / `amethyst_energy_dust` 等"核心材料" | 金属 | 0（按金属顺序） |
   | `raw_<metal>` | 金属 | 1 |
   | `<metal>_ingot` | 金属 | 2 |
   | `<metal>_nugget` | 金属 | 3 |
   | `<metal>_upgrade_template` | 金属 | 4 |
   | `<metal>_block` | 金属块 | 0 |
   | `<metal>_bricks` / `_pillar` / `_bricks_stairs` / `_bricks_slab` / `_bricks_wall` / `_door` / `_trapdoor` / `_bars` / `_chain` / `_lantern` | 金属建材 | 0..9 |
   | `<metal>_sword/_axe/_pickaxe/_shovel/_hoe/_helmet/_chestplate/_leggings/_boots` | 金属装备 | 0..8 |

   排序键 = `(分区种类, 金属序号, 区内序号)`；认不出来的物品落到该分区兜底的那一段（材料/建筑的"其他…"），不会丢物品。
3. 核心材料建议由 `MetalFamily.Spec` 直接携带（`coreItem`），这样新金属一行配置就自带核心材料 → 分区归属自动成立。

## 四、状态（1.4 定稿后）

- ✅ 机制已确认（源码级）；5 张横幅素材已放进资源目录
- ✅ 已实现：**一个**创造页（`bettergold:bettergold_tab`，`withTabsBefore(CreativeModeTabs.SPAWN_EGGS)`）+ 页内 5 个横幅分区
  + 客户端横幅渲染（`ScreenEvent.Render.Post`）+ 卷动行号；FD 乐事分区由 FD 模块自己注入（核心代码不引用 `FdItems`）

  逐元素比对 `getDisplayItems()` == 自算排布（0 处不一致）；排序表 12 项 = 原版 10 + 本模组 1 + 农夫乐事 1
- 【实测】`runClient`：真实渲染路径在滚动扫描中把 5 个分区的横幅全部画出（660 次绘制、5/5 分区命中），日志无异常
