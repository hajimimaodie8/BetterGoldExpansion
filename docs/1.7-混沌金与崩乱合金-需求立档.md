## 1. 素材入库结论（一句话 + 指针）

- **两份 zip 全部解开、逐条清点、SHA256 留档、归档进项目**：
  `docs/新约10-素材清单/`（`素材清单.md` 人读 + `素材清单.tsv` 机读 + `README.md` 归档说明 + `_识别证据/`）。
  **100 个文件 / 2,515,380 B**，**一个都没落进 `src`**。
- **模型技术路线已定（本轮最关键的一条结论）**：
  金钱妖是 **Blockbench「Modded Entity」导出 = 原版 JSON 实体模型**，
  **不是 GeoModel / GeckoLib**。依据（三条）：
  1. `money_gremlin.bbmodel` 的 `meta.model_format = "modded_entity"`、`resolution = 64×64`；
  2. `money_gremlin.java` 是 `extends EntityModel<T>` + `LayerDefinition.create(meshdefinition, 64, 64)`
     —— 纯原版 `ModelPart` 层级（17 个部件：`all/head{base,misc{A1,A2},eye}/body{ring,B1..B8}`）；
  3. `money_gremlin.animation.java` 是 `net.minecraft.client.animation.AnimationDefinition`
     （`AnimationDefinition.Builder` + `Keyframe` + `AnimationChannel`）—— 原版 1.19+ 关键帧动画系统。
  ⇒ **本仓 `build.gradle` 没有 GeckoLib**（只有 Farmer's Delight / Patchouli 两个 optional），
  所以这条路线**也是唯一可行**的：贴图 + `EntityModel` + `AnimationDefinition`，**零新依赖**。
- **配方读过多少：4 张截图 100% 读出来了**（逐格字节级 `EXACT`，见
  `_识别证据/配方逐格识别.md`）。反过来说，**只有这 4 条配方**；其余配方见 §7。
- **两套动画已找到**：`idle`（2.5 s，`looping`）与 `walk`（1.5 s，`looping`），**总共就这两套**。
  ⚠ 作者说的「闲置与追击模式」与该命名**不完全对齐** ⇒ §4 歧义 ③。

| `money_gremlin.bbmodel`（1,415,467 B） | Blockbench 工程：`modded_entity` / 64×64 / `animations = [idle, walk]` / 2 张参考图 / 内嵌贴图 sha256 与 `money_gremlin.png` **相同** |

**可执行口径（实现者可直接照做的部分）**
1. **技术路线**：`PathfinderMob`（或 `Monster`）子类 + `EntityType` 注册进 `registry/AllEntities.java`
   （现有唯一实体 = 投射物 `thrown_antique`，`AllEntities.java:20-26` 可当模板）。
   渲染 = 原版 `EntityRenderer<T, M>` + `EntityModelSet.bakeLayer(...)`；动画 = 把导出文件里的
   `AnimationDefinition` 常量搬进一个 `money_gremlinAnimation` 类，在 renderer 里用
   `AnimationState` + `KeyframeAnimations.animate(...)` 播（原版 `ArmorStand`/`Warden` 同款做法）。
   ⚠ 导出文件里的 `new ResourceLocation("modid", ...)` 是 **1.19 API**，1.21.1 要改成
   `ResourceLocation.fromNamespaceAndPath("bettergold", "money_gremlin")`。
2. **动画触发**：`idle` = 静止/未锁定目标时循环；`walk` = **移动中**循环（`walkAnimationSpeed > 0`）。
   ⇒ 「追击模式」是否就等于 `walk`？见 §4 歧义 ③。
3. **攻击**：与目标**间距 ≤ 3 格**时，每 **120 tick** 发射一次，一次 **8 枚**混沌金币；
   方向 = **以自身中心为原点**「米字」（8 向）；射程/速度/重力见 §4 歧义 ④。
   ⇒ 投射物建议复用**既有投掷物模式**：`item/ThrownAntique.java` + `AllEntities.THROWN_ANTIQUE`
   （`MobCategory.MISC`、`sized(0.25,0.25)`、`clientTrackingRange(4)`）。
4. **追击范围 32 格**：必须**分别写**「目标选择范围」与「跟随/丢失距离」两个数；见 §4 歧义 ③。
5. **掉落 / 生成方式 / 生命值 / 移速 / 伤害 / 音效：作者原话没给** ⇒ §7。
   ⚠ 本仓**没有 `sounds.json`**、没有 `EntityAttributeCreationEvent` 注册（读源码确认）
   ⇒ 这一包要**新增**属性注册、渲染器注册、生成蛋（或生成规则）、音效（或直接用原版音效）。
