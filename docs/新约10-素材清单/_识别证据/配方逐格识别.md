# 配方截图逐格识别（字节级证据）

> **方法（可复算）**：4 张 `配方图集/*.png` 是 JEI 界面的截图。实测网格几何：
> 格子 **160×160 px**、间距 20 px、第一格左上角 **(20,20)**；**物品贴图按 10 倍放大**绘制
> （扫描 `y=60` 得到颜色每 10 px 变化一次）⇒ 取每格 `(x0+10i+5, y0+10j+5)` 采样即可**逐字节还原 16×16 贴图**。
> 槽底灰度 = `(139,139,139)`；半透明像素按 `over(139,139,139)` 混合后再比。
> 候选集 = 原版 1.21.1 客户端 jar 的 `assets/minecraft/textures/item|block|mob_effect`（1656 张，
> 取自 `~/.gradle/caches/neoformruntime/artifacts/minecraft_1.21.1_client.jar`）
> ∪ 本仓 `src/main/resources/assets/bettergold/textures/item`（330 张）
> ∪ 本次两份 zip 的贴图（90 张）＝ **2046 张**；对每格计算 MD5(768 B) 做**精确匹配**。
> **判定**：`EXACT` = 该格还原出来的 16×16 与候选贴图**逐像素相同**（256/256）；`--` = 无精确匹配（另有物品）。

## 5) 归零结论

- 4 张配方截图里出现的**全部**输入物 = { 原版金块、原版金锭、原版青金石、原版书、原版铜锭、原版铁锭、
  原版下界合金升级锻造模板、万坚金升级锻造模板（既有）、万坚金锭（既有）、混沌金币串（既有）、
  混沌金锭、混沌金块、崩乱合金锭、混沌金币 } —— **没有一个读不出来**。
- ⚠ 反过来说：截图里**没有**出现 `混沌金盔甲/器具`、`崩乱合金器具/盔甲`、`禁果`、`火把花种子`、
  `高精度炼金油`、`混沌金锭(材料链)` 的配方 ⇒ 这些**只有作者文字**（或文字也没写全）⇒ 见立档 §7「待作者补」。

## 6) 附带人眼结论（非哈希）

- `万坚金砧 gui.png`（256×256）= 砧式界面：顶部一个**锤形图标 + 红色错误条**，下面一行
  `[槽] + [槽] → [槽]`（两输入一输出），再往下是**玩家背包 9×3 + 快捷栏 9×1**；左下角另有两条灰条（装饰/额外槽位）。
- `空槽中的混沌金币串图标.png`（16×16）= **灰色三连币**（幽灵提示图）；与既有
  `chaos_coin_string.png`（金色涡形）**不是同一张**，与 `混沌金币.png`（单枚带品红环）也不是。
  ⇒ 它是**万坚金砧 GUI 空槽的提示图标**（提示该槽放"混沌金币串"）。
- `金钱妖/例图1.jpg`（1580×850）= 造型美术参考：**金色方孔钱板**（方孔里有一只暗红竖瞳的**眼**）+
  一根**暗红绳**从上穿孔而下打结，钱板下方另有一**圆环**，环上垂挂 **8 枚金色方孔钱**。
  ⇒ 与 `money_gremlin.java` 的部件完全对应：`head{base(钱板) + misc + A1/A2 + eye}`、
  `body{ring(圆环) + B1..B8(8 枚垂挂钱)}`。
- `金钱妖/色卡.png`（16×16）= bbmodel 工程内的**参考图**（`reference_images[1]`，位置 158,160），
  **不是** 8×1 的纹饰色卡，别误落到 `textures/trims/color_palettes/`。
- `money_gremlin.bbmodel` 的 `textures[0].source` 内嵌贴图，解 base64 后
  **SHA256 = ab6094115e8fcaef2f24cddd2cd4e0ff27303dde5675eba9a17f8006d0672ab0 = `money_gremlin.png` 本体**
  （2156 B）⇒ 模型与贴图配套，无版本错配。
