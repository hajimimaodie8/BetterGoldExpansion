## ⚠ 文件名编码修正（金钱妖.zip）

那个 zip 的条目名是 **UTF-8 字节但没置 UTF-8 标志位**，`.NET ZipArchive` 按系统 ANSI(936) 解码 ⇒ 解出来是两个乱码名。
**处置**：归档时按 `GBK 编码 → UTF-8 解码` 还原成作者本意，并在此留档：

| zip 内的乱码名 | 还原后的真名 | 证据 |
|---|---|---|
| `渚嬪浘1.jpg` | `例图1.jpg` | `"渚嬪浘1.jpg"` 的 GBK 字节 = `E4 BE 8B E5 9B BE 31...` = UTF-8 的「例图1」 |
| `鑹插崱.png` | `色卡.png` | 同法：`"鑹插崱"` 的 GBK 字节 = `E8 89 B2 E5 8D A1` = UTF-8 的「色卡」 |

（`more useful gold 新约10.zip` **没有**这个问题，文件名本来就是中文，直接解包即可。）

## 复算方式

```powershell
# 清单里每一行的 SHA256 都可以这样复算
Get-ChildItem <本目录> -Recurse -File | ForEach-Object { "{0}  {1}" -f (Get-FileHash $_.FullName -Algorithm SHA256).Hash.ToLower(), $_.Name }
```
