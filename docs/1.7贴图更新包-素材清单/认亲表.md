# 1.7 贴图更新包 —— 认亲表（逐文件）
识别方法（可复算）：同尺寸前提下算 **逐像素 RGBA 平均绝对误差 MAE**；类内用 `scipy.optimize.linear_sum_assignment` 做全局一对一指派；`2nd` = 同尺寸类内次优目标的 MAE；`ratio = 2nd/MAE`；`原版` = 与原版 `client-extra.jar` 内同尺寸贴图的最小 MAE（排除「这不是我们的」）。
判定三条同时满足 = **确定**：`MAE ≤ 2.0` + `ratio ≥ 1.5` + `alpha 掩码与不透明像素数与目标完全一致`。
