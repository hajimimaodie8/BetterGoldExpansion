# 新增一种材料家族：检查清单

本模组以后要加 16 种新建材（锭 / 粒 / 块 / 砖 / 门 / 台阶 …）。为了让这件事不用一种材料改一堆文件，
标签被组织成"**家族标签 → 桥接标签**"两层结构：**只往家族标签里加一次，就自动进入原版和通用标签**。

## 一、家族标签（本模组自己的）

| 文件 | 放什么 |
|---|---|
| `data/bettergold/tags/item/ingots.json` | 所有"锭" |
| `data/bettergold/tags/item/nuggets.json` | 所有"粒" |
| `data/bettergold/tags/item/raw_materials.json` | 所有原材料（粗矿） |
| `data/bettergold/tags/item/storage_blocks.json` | 所有材料块（物品） |
| `data/bettergold/tags/block/storage_blocks.json` | 所有材料块（方块） |

## 二、桥接标签（已经写好，不用再动）

这些文件的内容是 `"#bettergold:xxx"`，也就是说家族标签里的东西会自动流进去：

| 家族标签 | 自动进入 |
|---|---|
| `#bettergold:ingots` | `#c:ingots`、`#minecraft:beacon_payment_items` |
| `#bettergold:nuggets` | `#c:nuggets` |
| `#bettergold:raw_materials` | `#c:raw_materials` |
| `#bettergold:storage_blocks`（物品 / 方块） | `#c:storage_blocks`（物品 + 方块）、`#minecraft:mineable/pickaxe` |

## 三、加一种新金属材料的完整步骤

1. **写规格**：在 `material/AllMetals.java` 里加一份 `MetalFamily.Spec`
   （`new MetalFamily.Spec("<英文id>", "<中文名>")`）—— tier 数值、盔甲数值、`coreItem`，以及可选的
   `autoSmelt()` / `thunderStrike()` / `contactEffect(...)` 全都写在这一份 Spec 里。材料链（锭/粒/原料）、
   全套建材、五件器具、四件盔甲、升级锻造模板都由它**一次注册**，不用再碰 `AllItems` / `AllBlocks`。
   （`AllTiers` 现在只放**非家族工具**——古董 ANTIQUE / 下界合金古董 NETHERITE_ANTIQUE，加金属不用动它。）
2. **批量产出资源**：在 `tools/asset-generator/` 下依次跑（都加 `--apply`）：
   `generate_metal_assets.py`（贴图 / 方块状态 / 模型）、`generate_metal_data.py`（语言 / 战利品表）、
   `generate_metal_tags.py`（家族标签 + 原版类别标签 + 挖掘等级）、`generate_metal_recipes.py`（整条配方链）、
   `generate_metal_trims.py`（纹饰材料）。每个生成器里都有一份金属清单（`METALS`），记得补上新金属那一行；
   跑完再用 `validate_metal_assets.py` / `validate_metal_data.py` 两个校验器确认没漏文件。
3. **进家族标签**：不用手写 —— `generate_metal_tags.py` 把锭/粒/原料/材料块写进 `bettergold:ingots` /
   `nuggets` / `raw_materials` / `storage_blocks`（物品 + 方块）。**只加这一次，通用标签和原版标签就都齐了**
   （桥接标签里写的是 `"#bettergold:xxx"`）。挖掘工具类型与挖掘等级（`minecraft:mineable/pickaxe`、
   `minecraft:needs_diamond_tool`）也由这个生成器一并写入。
4. **工具**：`Tier` 由第 1 步的 Spec 现场构造（**不写 `AllTiers`**）；五件器具进对应的类别标签由
   `generate_metal_tags.py` 负责，否则**附魔台不会给它们附魔**：
   `minecraft:swords` / `pickaxes` / `axes` / `shovels` / `hoes`。
   （1.21 的 `#minecraft:enchantable/*` 全部由这些类别标签拼出来。）
5. **盔甲**：盔甲材质同样由 Spec 构造（**不再有 `AllArmorMaterials`**）；四件套进
   `head_armor` / `chest_armor` / `leg_armor` / `foot_armor` 也由 `generate_metal_tags.py` 负责。
   这一步同时决定"能不能附魔"和"能不能打盔甲纹饰"。
6. **配方 / 战利品表 / 模型 / 语言**：全部交给第 2 步的生成器批量产出，不用照着现有材料手工改名。
7. **（可选）让它能当纹饰材料**：`generate_metal_trims.py` 会一次补齐下面四样，缺一个都不生效：
   - `data/bettergold/trim_material/<asset_name>.json`
   - `assets/bettergold/textures/trims/color_palettes/<asset_name>.png`（8×1 色卡）
   - 在 `assets/minecraft/atlases/armor_trims.json` 的 `permutations` 里加 `<asset_name>: bettergold:trims/color_palettes/<asset_name>`
   - 把材料物品加进 `minecraft:trim_materials`

## 四、给外部模组 / 数据包的扩展点

- 想让**别的模组**的物品被本模组当作"锭"用：对方在自己数据包里往 `data/bettergold/tags/item/ingots.json`
  追加自己的物品即可，本模组不需要改代码。
- 代码层面引用这些标签：用 `com.hjmmd_8.bettergold.api.BetterGoldTags`
  （`INGOTS` / `NUGGETS` / `RAW_MATERIALS` / `STORAGE_BLOCKS` 以及 `isIngot(ItemStack)` 之类的便捷方法）。
