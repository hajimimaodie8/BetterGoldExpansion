## 实测教训（本轮真踩过，必须记）

第一版扰动脚本是 **PowerShell 5.1** 写的，两个坑叠加把源码写坏了：

1. `.ps1` 里的中文路径被 PowerShell 5.1 按 **ANSI** 读 ⇒ 备份路径变乱码 ⇒ `Copy-Item` 备份失败（没有任何备份）；
2. 用 `Get-Content`（按 ANSI 解码）→ `[IO.File]::WriteAllLines`（按 UTF-8 编码）"修复"文件 ⇒
   **Java 文件里所有中文注释被双重编码写坏**（不可逆：解码时已经出了 `?`）。
   ⇒ 只能用 `git checkout` 还原该文件、把 13 处改动重做一遍（编译与全部关卡已重新跑绿）。

口径：**任何"改源码/复原"都必须走 bytes（`shutil.copyfile` / Python `write_bytes`），不许用 PowerShell 的文本读写管道。**
