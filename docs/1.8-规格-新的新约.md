### Z-3.4 ★「伤害 / 攻速」两个数的口径（**与 §G 原文的对应**）

SpearCore 的 `Stats` 里：
- `attackDamageBonus` 是 `ATTACK_DAMAGE` 的**修饰值**（玩家基值 1.0 由引擎加）⇒ **工具提示 = 字段 + 1**；
- `attackDuration` 是「**一击几秒**」，工具提示的攻速 = `1 / attackDuration`
  （`Stats#getAttackSpeedModifier() = 1/attackDuration − 4.0`，3.2.1 字节码）。

§G 那张表给的是**字段值**（证据：§G-31 的 1.05 / 1.075 与库自带钻石矛
`SpearStats.DIAMOND`（bonus 3.0 / 1.05 / 1.075）**逐位相同**，且 §G-31 自己写着「同钻石矛」）。
所以实现照字段写；A 级读数同时给出「字段 / 窗口」，工具提示请读者自行 +1 / 取倒数。
