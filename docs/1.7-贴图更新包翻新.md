## §2 认亲方法（可复算）

1. **精确层**：SHA256 全等 → 分数 1.0。本轮 0 条。
2. **像素层**：同尺寸前提下，对每个 (zip 文件, 候选目标) 对算
   **逐像素 RGBA 平均绝对误差 `MAE = mean(|A - B|)`**（含 alpha 通道）。
3. **指派层**：同尺寸类内用 `scipy.optimize.linear_sum_assignment` 做**全局一对一指派**（最大化 -MAE），
   每个目标恰好被一张 zip 认领 ⇒ 天然给出「与第二名的差距」`ratio = 2nd_MAE / best_MAE`。
4. **三条硬校验**（同时满足才算「确定」）：`MAE <= 2.0`、`ratio >= 1.5`、
   **与目标的 alpha 掩码逐字节相同且不透明像素数相同**（= 同一条美术血脉）。
5. **候选集**：A = 仓库 `src/main/resources/assets/bettergold/textures/**`（626 个文件）；
   B = `docs\新约10-素材清单\新约10\**`（上一包 94 张，作语义交叉验证）；
   C = 原版 jar 内贴图（⚠ 本机**没有** 1.21.1 客户端 jar，用
   `~/.gradle/caches/forge_gradle/minecraft_repo/versions/1.20.1/client-extra.jar` 的 2431 张，
   仅用于「排除这不是我们的」）。

**结果：72 张全部判为「确定」，0 疑似，0 认不出。** 每张的 MAE 都 `<= 1.88`，
对原版的最小 MAE 是 `3.99–45.1`（差 2–40 倍）；类内次优差距 `1.8x–75.5x`。
**族顺序在 9 个类里完全一致**（flame → sturdy → thorns → echo → indigo → voodoo → thunder → illusion），
这是第 4 条独立佐证 —— 其中 7 个类的类内差距是 4–75 倍，足以锚定这个顺序。

检查项：
- ① 72 张授权替换：SHA == 钉住的改后 SHA，且 **!= 改前 SHA**（`[bg17tex-revert]` 反空转）
- ② 554 张未授权：负向断言，一个字节变红（`[bg17tex-untouched-fail]`）

- ④ 正向 needle：被替换的 64 张（非盔甲）仍被模型 JSON 引用（`[bg17tex-model-ref]`）
- ⑤ 正向 needle 跑在**去注释源码**上：`MetalFamily.java` 剥掉 `//` 与 `/* */` 后仍含
  `ArmorMaterial.Layer` + `ResourceLocation.fromNamespaceAndPath(bettergold.MODID, this.id)`

### §4.1 并发会话下的读数时间线（必须一起读）

本轮**不是独占工作树**：开工时 `git status` 就有另一个会话（`bg-n10rc` 配方）的未提交改动，
它在**本轮工作期间**自行提交（HEAD `f9e60eb` → `7680845`），随后又继续改 Java。
因此"七关卡全绿"是**某一时刻**的读数，必须连时间线一起报：
